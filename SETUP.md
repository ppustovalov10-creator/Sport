# Как развернуть многопользовательскую версию

Инструкция для **Claude Code** — открой его, укажи на эту папку, дай прочитать
этот файл.

## Что изменилось по сравнению с личной версией

- Убрана вся моя личная история тренировок и питания — каждый новый аккаунт
  начинается с чистого листа
- При первом входе — анкета (пол/возраст/рост/вес/цель), которая сама
  считает калории и БЖУ под конкретного человека, вместо моих зашитых цифр
- Настоящий вход: email + пароль, каждый видит только свои данные
- `js/storage-supabase.js` теперь **обязателен**, а не опционален — без
  Supabase эта версия вообще не откроется (в отличие от личной версии,
  которая работала на телефоне без базы данных)

## Шаг 1 — Supabase-проект (база данных + логины)

1. Зарегистрируйся на supabase.com → New Project (бесплатный тариф хватит
   на старте — до 50 000 активных пользователей в месяц)
2. Authentication → Providers → Email — убедись, что включён (обычно по
   умолчанию). Реши, нужно ли подтверждение по почте (Confirm email):
   включено — безопаснее, но новый человек не сможет войти сразу;
   выключено — проще для друзей/семьи, кто тебе доверяет
3. SQL Editor → New query → вставь содержимое `supabase/schema.sql` → Run
4. Project Settings → API → скопируй `Project URL` и `anon public key`

## Шаг 2 — Подключить ключи

Дай эти два значения Claude Code и попроси подставить их в
`js/storage-supabase.js` вместо `YOUR-PROJECT` и `YOUR-ANON-KEY` (в начале
файла, переменные `SUPABASE_URL` и `SUPABASE_ANON_KEY`).

## Шаг 3 — Проверить локально

Попроси Claude Code поднять локальный сервер и пройти весь путь вживую:
регистрация нового аккаунта → анкета → главный экран → выход → повторный
вход тем же аккаунтом (данные должны сохраниться). Это должно быть
проверено по-настоящему, не на словах.

## Шаг 4 — Задеплоить

Как и раньше — попроси Claude Code выложить на Vercel/Netlify/аналог.
Дальше просто рассылаешь ссылку тем, кому нужно — каждый регистрирует
свой аккаунт сам.

## Про ИИ-анализ еды (фото/текст)

**Переключено на Google Gemini API — генуинно бесплатно, без карты, без
лимита по времени.** Anthropic Console требует привязать оплату прежде
чем можно сделать хоть один запрос — это и было причиной, по которой
анализ еды не работал весь день.

Как получить ключ (для каждого пользователя приложения свой):
1. aistudio.google.com → войти через Google-аккаунт
2. "Get API key" → "Create API key" → скопировать
3. В приложении → 🔑 → вставить

Бесплатный лимит: 15 запросов в минуту, 1500 в день — с большим запасом
для личного использования. Карта не нужна никогда, если не захочешь
более высокие лимиты.

## Честно о масштабе ответственности

Если это будут не только близкие друзья, а вообще открытая регистрация —
подумай заранее:
- Пароли и здоровье (вес, питание, тренировки) других живых людей — это
  чувствительные данные, ты становишься за них ответственным
  технически, даже без юридических обязательств
- У Supabase есть бесплатный лимит — при реальном росте числа людей
  придётся перейти на платный тариф
- Нет функции "восстановить пароль" настроенной специально — Supabase
  Auth умеет это из коробки (Reset Password), но письмо шаблон стоит
  проверить перед тем как звать много людей

Для круга друзей/семьи (до нескольких десятков человек) всё это не
проблема. Для публичного продукта — стоит отдельно обсудить, прежде чем
звать первых 100 людей.
